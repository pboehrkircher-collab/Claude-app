# Müllerball – Hügelflug

Ein Hügel-Flug-Spiel im Browser: Der Müllerball rollt über bunte Hügel.

- **Halten** (Touch, Maus, Leertaste, Pfeil runter) = Ball wird schwer und taucht ab
- **Loslassen** = Ball wird leicht und fliegt über Kuppen
- Sauber auf Abhängen landen → Speed-Boost und Bonuspunkte, 3× in Folge → **Fever**
- Checkpoints (Fahne) geben +15 s, bevor die Nacht kommt

## Starten

```bash
python3 -m http.server 8000
```

Dann http://localhost:8000 öffnen. Auf dem Handy lässt es sich über „Zum Home-Bildschirm“ als App installieren.
